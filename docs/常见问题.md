## 角色跑着跑着就停住动作，像在地上滑动

**现象**
Ported 里的角色按 WASD 移动，跑一小会儿后动作定格，角色继续移动，看起来像滑动。不按空格也会出现。待机动画不受影响。

**原因**
移植来的跑步、跳跃动画片段（如 `an_11008@run_R.FBX`）导入时没有开 `loopTime`，播完一遍就停在最后一帧。`idle` 片段设置了 `loopTime: 1`，所以待机正常。

Animator Controller 的 `run`、`jump_*` 状态没有出口迁移，所以不是状态机自己切走了。

**解决**
在 `HeroController` 里运行时处理：循环状态（待机、跑步、`jump_loop`）播完后重新播放。

- `PlayLoop(candidates, repeat)`：`repeat=false` 用于 `jump_start`、`jump_end` 这类只播一次的动画。
- `RepeatLoopIfFinished()`：当前状态的 `normalizedTime >= 1` 且状态本身不循环时，用 0.1 秒的交叉淡入重新播放。
- 没有去改 FBX 的导入设置：每个角色有很多动画片段，逐个配置的工作量大，而且 Unity 开着时改 `.meta` 容易被覆盖。

**注意**
首尾帧不一致的动画，在每个周期衔接处会有轻微的接缝。接缝明显的话，可以把 0.1 秒的淡入时间调长，或者改成修改 FBX 导入设置里的 `loopTime`。
